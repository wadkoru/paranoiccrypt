# ParanoicCrypt

Ховає файл усередину звичайної на вигляд картинки-мема. Шифрування — на пристрої,
нічого не надсилається в мережу.

- **Шифрування:** AES-256-GCM, ключ 256 біт, новий для кожного файлу
- **Стеганографія:** дані в двох молодших бітах кольорових каналів PNG
- **Термін дії:** необовʼязковий таймер, вшитий у підписаний заголовок
- **Офлайн:** після першого відкриття сторінка працює без інтернету

## Чесно про межі

- Термін дії — правило програми, а не математики: хто має картинку і ключ,
  може перевести годинник. Гарантовано «спалити» файл офлайн неможливо.
- Картинка ховає файл від випадкового ока, але не від стего-аналізу.
- Месенджер, який стискає фото, знищить сховані дані — надсилати треба файлом.
- Загублений ключ означає, що файл не відкриє ніхто й ніколи.
